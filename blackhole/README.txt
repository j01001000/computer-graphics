HW11: Black Hole Ray Trace OpenCL

Jun Hong
CSCI4239/5239 Spring 2026


Ray trace a black hole using simplified null geodesic acceleration.
Computations are accelerated using OpenCL and OpenMP.
Debugging annd refactoring were done mostly by Github Copilot.
Gemini and various textbooks were used to obtain equations from general relativity.

Key bindings
  g          Toggle OpenCL/OpenMP rendering
  +/-        Increase/decrease distance between spheres
  n/N        Increase/decrease maximum number of reflections
  []         Move light
  a          Toggle axes
  arrows     Change view angle
  PgDn/PgUp  Zoom in and out
  0          Reset view angle
  ESC        Exit
